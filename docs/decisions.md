# Build decisions — 2026-11-11

Ajay authorized the Phase 0 build and a private GitHub repository in this conversation.
The original spec is preserved in SPEC.md. These documented corrections govern implementation.

1. **Phase 0 only.** No paid dashboard, accounts, billing or Phase 2 fix engine. Gate 1 remains required before Phase 1. Nothing is deployed publicly yet; Ajay's staging review remains a launch gate.
2. **GitHub stores the code.** GitHub Pages cannot execute Flask, workers or PostgreSQL. Docker/Fly.io deployment configuration is supplied; an application hosting account is still needed.
3. **Measurement corrections accepted in the conversation.** Show traditional Google demand and sampled citation rate separately. Remove lost-search/customer claims, combined gap math and sessions-per-sample CTR. GSC does not separately expose AI Overview / AI Mode traffic through its ordinary search reporting.
4. **Gemini disabled under §9.3 and §17.11.** Google's current grounding terms explicitly restrict analysis, storage and monitoring of grounded results for this purpose. No Gemini API calls are made. The UI discloses the exclusion; it is excluded from scoring. See vendor-check.md. The spec's three-engine launch criterion cannot currently be claimed fulfilled.
5. **Google AI Overview absent is a distinct result.** Do not treat a missing overview as an answer that omitted the business. Exclude it from the answer citation denominator, and show that distinction in evidence.
6. **Citations, not arbitrary retrieval results.** Perplexity url_citation annotations or explicit numbered references are resolved to sources. A source appearing only in retrieved search results is not counted. Source domains can be directories, publications or competitors; the UI calls them other cited sources rather than pretending all are competing businesses.
7. **Recommendations are hypotheses.** A limited crawl cannot establish that a site has no answering page or that missing schema caused an omission. State the pages checked and specific observations. No fabricated business facts or reviews in suggested copy.
8. **Costs use decimal dollars.** Integer cents would round sub-cent calls and distort scan economics. Provider-reported cost and unknown cost are separated in the ledger; never call a rate-based estimate an actual bill. The $0.30 provisional budget is an alert threshold, not a verified cost promise or hard spending cap. Unknown-cost attempts require a billing reconciliation before launch.
9. **Credential-free preview.** Ajay has no hosting/API accounts yet. Live scans are off by default; sample reports are fictional and labeled SAMPLE. No sample records or events enter real analytics. The original spec's market figures are not used in product copy.
10. **Free-scan privacy.** Public reports use 192-bit random tokens, ask search engines not to index them, and do not expose captured email addresses. Free-scan retention is 90 days; purge and deletion commands are documented.
11. **Location scope in the first adapters.** Google SERP and demand use the configured United States location. Suggested local questions name the visitor's city. Results are not described as precise city-geolocated consumer answers. Exact city location-code validation remains a launch requirement if city-geolocated coverage is advertised.
12. **Assets.** The local npm registry returned 503. Use the official pinned Tailwind standalone binary with its published SHA-256 and locally vendored HTMX 2.0.8. No CDN script dependency for the main UI.
13. **Retries.** Retry explicit 429/502/503/504 responses twice with backoff. Do not retry timeouts with ambiguous billing. Idempotent task claiming prevents duplicate queued deliveries from running the scan twice. Stuck jobs require investigation, not automatic paid replay.
