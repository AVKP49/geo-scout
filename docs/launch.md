# Phase 0 launch checklist

This is a build in progress, not a declaration that §3.7 is satisfied.

- [ ] Hosting account with staging PostgreSQL and Redis; costs accepted.
- [ ] DataForSEO and Perplexity accounts configured as hosting secrets.
- [ ] Turnstile hostname/site keys, production SECRET_KEY and correct trusted proxy hops.
- [ ] Remaining provider storage/redistribution terms reviewed for the intended report.
- [ ] Authenticated API fixtures recorded without secrets; citation parsing validated.
- [ ] Per-scan bill reconciled, including retries/timeouts; realistic budget accepted.
- [ ] Real scan completes in <5 minutes; every engine failure state verified on staging.
- [ ] ≥85% manual agreement on the spec's sample, or coverage/criterion revision explicitly recorded.
- [ ] Gemini exclusion reviewed with Ajay; do not claim a three-engine acceptance pass.
- [ ] Postmark sending domain, SPF/DKIM and appropriate transactional/follow-up streams verified.
- [ ] Report email, day-3/day-7 sequence and one-click unsubscribe verified.
- [ ] Founder calendar URL; confirmed-booking metric procedure tested.
- [ ] Production retention/deletion/backup job scheduled and verified.
- [ ] HTTPS, mobile/accessibility checks, secret scan, dependency audit and CI pass.
- [ ] Ajay reviews staging and explicitly approves production (§12.2).
- [ ] Production URL published, rollback image identified, Gate 1 start date recorded.

Gate 1 runs for two weeks after launch: ≥100 completed scans, ≥20% email capture,
≥10 genuinely booked calls. No Phase 1 development before the gate passes.
